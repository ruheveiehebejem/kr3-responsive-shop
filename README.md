# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание
Проект основан на HTML/CSS-проекте КР №1 ShopProject. Исходные главная страница, каталог, контакты, основные стили и JavaScript перенесены из репозитория `kr1-html-css-shop-`. Добавлены недостающие страницы товара и заявки и адаптивные стили из практического занятия №12.

Bootstrap в проекте КР №3 не используется.

## Практическая работа №12 — адаптивная вёрстка
- перенесены исходные HTML/CSS/JS-файлы КР №1;
- добавлен отдельный файл `css/responsive.css`;
- на всех пяти страницах добавлен `meta viewport`;
- `responsive.css` подключён после `style.css`;
- применён подход Mobile First и медиазапросы;
- адаптированы шапка и навигация, hero-блок, сетка карточек и каталог с фильтром;
- добавлен элемент `picture` для изображения товара;
- адаптированы форма заявки и таблица характеристик.

В исходном репозитории КР №1 папки `images/` не было. Поэтому добавлен нейтральный SVG-заполнитель `images/product-placeholder.svg`; его можно заменить реальным изображением, сохранив HTML-структуру.

## Практическая работа №13 — доступность
- добавлена ссылка пропуска к основному содержимому (`skip-link`);
- на каждой странице предусмотрен основной заголовок `h1`;
- навигация имеет доступное название, текущая страница помечается `aria-current="page"`;
- добавлен видимый фокус `:focus-visible`;
- поля форм связаны с подписями `label`;
- изображения имеют текстовые описания `alt`;
- таблица содержит `caption`, заголовки и ячейки;
- для таблицы на узком экране предусмотрена горизонтальная прокрутка внутри контейнера.

### Lighthouse
Выполнить Lighthouse-аудит категории Accessibility для `index.html`, `catalog.html` и `order.html`. После проверки сохранить настоящий HTML-отчёт или скриншот в папку `lighthouse/`. Баллы Lighthouse до запуска проверки не заявляются.

## Проверяемые ширины
360px, 430px, 768px, 1024px и 1440px.

Проверить шапку, навигацию, hero-блок, карточки, каталог, фильтр, страницу товара, таблицу, формы, контакты и подвал. Отдельно проверить отсутствие горизонтальной прокрутки всей страницы.
